ÉLAN BOUTIQUE — PROJECT SOURCE CODE

This folder contains the original 14 HTML pages and original style.css from your uploaded boutique website ZIP.
The original page designs and styling have been retained. app.js adds browser-side validation and editable demo data.

HOW TO RUN
1. Extract this folder.
2. Open this exact folder in VS Code (File > Open Folder).
3. Keep all HTML files, style.css and app.js together.
4. Right-click index.html and choose Open with Live Server.
5. Use the website navigation to open the Admin Login.

WHAT WORKS IN THIS VERSION
- Admin can add products and save product edits.
- Saved products are reflected on the Collections page after refresh.
- Wishlist heart selections are saved.
- Gallery additions and edits are saved in browser storage.
- Order status selections can be saved.
- Contact and custom-design forms validate and save submitted entries.
- New contact messages appear in Manage Messages.

IMPORTANT LIMITATIONS
This is a front-end college demonstration using localStorage. Data is saved only in the same browser profile on the same computer. Clearing browser data, using another browser/device, or opening a different browser profile will not share the saved data.
The demo login is not secure authentication. Do not use it for a real business.
Image fields require a direct image URL (not a Google share/search page). You may also use a relative image path if the image file is placed inside this project folder.
The original visual design has been preserved; JavaScript is added as a separate shared file.
